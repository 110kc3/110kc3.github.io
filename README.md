# 110kc3.github.io

Domain-root discovery and AI agent readiness hub for 110kc3 portfolio web projects and services.

## Highlights

- **AI Agent Discovery:** Serves root-level `llms.txt`, `llms-full.txt`, and `.well-known/agents.json` discovery endpoints for autonomous web agents
- **Search & Crawler Indexing:** Canonical `robots.txt` and unified `sitemap.xml` mapping across hosted GitHub Pages projects
- **Security Protocols:** Hosts standard `.well-known/security.txt` vulnerability reporting definitions
- **Fast Static Hosting:** Pure zero-build static architecture hosted on GitHub Pages
